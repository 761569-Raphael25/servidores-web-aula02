Servidor local

É utilizado durante o desenvolvimento e os testes. É acessível apenas no próprio computador ou em uma rede interna.

Servidor remoto

É utilizado para hospedar aplicações que podem ser acessadas pela internet por usuários autorizados.

Ambiente de desenvolvimento

É o ambiente utilizado pelos programadores para construir e testar aplicações localmente, sem afetar os usuários reais.

Ambiente de produção

É o ambiente em que a aplicação está disponível para os usuários finais, exigindo estabilidade, desempenho e segurança.

Exemplo prático

Durante os testes uso o XAMPP no computador. Depois dos testes, publico o sistema em um servidor remoto para permitir o acesso pela Internet.
